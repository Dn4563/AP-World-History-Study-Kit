# Trees

One fenced block per hierarchy.

```
THE MONGOL EMPIRE (Genghis Khan, 1206–1227)
├─ Yuan Dynasty ........ China (Kublai Khan; 1271–1368; Ming ends it)
├─ Il-khanate .......... Persia / Southwest Asia (Hulegu; Persian officials)
├─ Golden Horde ........ Russia (Batu; tribute through Russian princes)
└─ Chagatai Khanate .... Central Asia (most traditionally Mongol)

```

```
NETWORKS OF EXCHANGE, 1200–1450
├─ Silk Roads ........... overland (Central Asia)
├─ Indian Ocean ......... maritime (monsoon zones)
└─ Trans-Saharan ........ desert overland (camel caravans)

```

```
CONSEQUENCES OF CONNECTIVITY
├─ Cultural
│  ├─ Religions: Buddhism, Hinduism, Islam, Neo-Confucianism, Chan (Zen)
│  ├─ Technology and learning: gunpowder, paper, translation
│  ├─ Cities: grow (Hangzhou, Samarkand, Timbuktu, Malacca) or decline (Kashgar, Constantinople, Baghdad)
│  └─ Travelers: Marco Polo, Ibn Battuta, Margery Kempe
└─ Environmental
   ├─ Crops: Champa rice, bananas, citrus, sugar
   ├─ Degradation: overgrazing, deforestation, soil erosion
   └─ Disease: bubonic plague (Black Death)

```
